What this sample proves

Docket does not guess vendor risk. It reads dated public records against the legal name the buyer supplies. Nicknames and DBAs are a second pass, never a substitute for the legal name.

1. USASpending — awards, not vibes

  • Operator action: search the legal entity string. Record awarding agency, obligated amount, action date, and award ID. A zero-hit search is a result, not a failure — write “no public awards under this exact string” with the search timestamp.
  • Cite: USAspending public award data. usaspending.gov.
  • Cite: USAspending API. api.usaspending.gov.

2. SAM.gov — registration, not a filing

  • Operator action: look up the same legal name. If a UEI or CAGE is public, copy it. If the entity is not registered, write that. Docket never files SAM and never renews a registration.
  • Cite: SAM.gov entity information. sam.gov.

3. OFAC SDN — dated named-entity screen

  • Operator action: screen the exact legal name against the SDN list on a recorded UTC date. Match / no-match plus the list publication used. A screen is not a clearance letter.
  • Cite: OFAC Specially Designated Nationals human-readable lists. ofac.treasury.gov SDN lists.
