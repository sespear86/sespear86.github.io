What this sample proves

Tender drafts. A human sends. Every section of a pack names the buyer note it came from, or it is marked “missing — do not invent.” Invented past performance is a fail.

1. Read the solicitation as published, not as rumor

  • Operator action: if the buyer names a public opportunity, pull the posted notice. Copy the title, notice ID, due date, and NAICS as printed. If the notice is gone, write that. Do not reconstruct a due date from memory.
  • Cite: SAM.gov contract opportunities (read-only). sam.gov.
  • Bound: Tender never clicks Submit. Tender never creates a SAM entity. Docket’s standing work is a different product.

2. Outline before prose

  • Operator action: map buyer notes onto a section list first: cover, understanding, approach, staffing, past performance, pricing worksheet (numbers only the buyer supplied). Empty sections stay empty and flagged.
  • Cite: Acquisition.gov FAR as a public structure reference, not as legal advice. acquisition.gov.
  • Bound: a FAR citation in a draft is a pointer. It is not an opinion that the buyer complies.

3. Past performance is records, not adjectives

  • Operator action: if the buyer names prior work, prefer a public award ID over a slogan. If no public award exists, say so and use only the buyer’s supplied fact sheet.
  • Cite: USAspending public awards as a lookup, not a bid. usaspending.gov.
  • Bound: Tender will not write “we have performed X” unless the buyer supplied X. Impersonation is a fail.
